## 本版本内容

- 为 `client.socket` 增加 `select` 和 `poll`，等待整数 socket 句柄读写就绪；
- 增加独立的 `skyuv_target_compile_utf8()`，供指定 MSVC/clang-cl 目标启用 UTF-8 源码编码。

## 已知限制与后续工作

- `client.socket` 只覆盖出站 TCP 客户端用途，不等同于完整 lsocket；
- `v0.2.0` 正式版的固定 Linux 性能基线、配置/日志/PID 路径约定、独立 Lua 解释器动态模块 `require` 验证和交付收口尚未完成；
- 本预览版不承诺稳定公共 ABI，也不建议未经验证直接用于生产环境。
