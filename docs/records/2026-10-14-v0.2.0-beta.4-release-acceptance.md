## 范围与限制

本版交付 Windows 第三方 CRT、编码与 unused 诊断策略和可恢复审查开关，修复 libuv
IPv6 初始化括号、亲和性高位移位及 stat 回退路径问题；补齐 Windows 构建运行目录、DLL
部署检查、客户端实际加载及测试准备同步。正式工作流修复了选择性构建无法满足运行布局
fixture 的问题；首次失败演练未创建公开资产。详细范围见 [beta.4 文档](../versions/v0.2.0-beta.4.md)。

第三方剩余诊断已有保留依据，不承诺全部零警告；旧 Windows stat 回退的公共 API 全链路
未覆盖，测试证据来自实际函数夹具。解释器仍不加入运行时安装包。0.x 不承诺稳定 ABI。
固定 Linux 权威性能基线、配置/日志/PID 路径约定、独立 Lua 动态模块验证与正式 v0.2.0
收口继续分别跟踪，不因本次预览发布自动完成。
