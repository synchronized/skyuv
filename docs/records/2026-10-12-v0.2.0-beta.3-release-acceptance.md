## 范围与边界

本版完成 client.socket 的 libuv 迁移、统一 client 模块、连接诊断与超时、有界接收、
半关闭、就绪等待、Lua GC 与 stdin 生命周期处理，并提供可选独立 Lua 解释器构建目标。
解释器暂不加入运行时安装包。
接口行为以 [客户端指南](../guides/client-socket.md) 为准；版本范围见
[beta.3 文档](../versions/v0.2.0-beta.3.md)。

本版不代表正式 v0.2.0 已完成。固定性能基线、路径约定、外部 Lua 模块计划及 Windows
构建诊断治理继续分别跟踪，不因本次发布自动完成。0.x 不承诺稳定 ABI。
