## 兼容性与后续

0.x 不承诺稳定 ABI、任意 Lua C 模块二进制兼容、长期噪声分布或固定性能提升。
Runtime 归档不包含可选独立 Lua 解释器；Windows 不支持 Unix daemon 或旧 `int fd` 外部句柄接管。
完整行为与迁移步骤见[发行包指南](../guides/runtime-distribution.md)。

本记录提交仅补充发布事实、版本状态与文档链接，不移动 `v0.2.0` tag，不更改或替换公开归档。
后续代码变化进入新版本，不能复用已发布 tag 或资产名称。
