# v0.1.1：统一 skyuv 运行时目标名称

## 状态

**已于 2026-09-29 正式发布。** 本版本是 `v0.1.0` 的补丁版本，不改变运行时语义和公共 ABI
承诺。

## 版本目标

将主便携运行时的 CMake target、构建产物和用户启动入口统一命名为 `skyuv`，避免使用
`skyuv_skynet_portable` 这类实现细节名称。

## 固定范围

| 范围 | 本版本变更 | 验收 |
|---|---|---|
| CMake 主目标 | `skyuv_skynet_portable` 重命名为 `skyuv` | CMake target 和三平台构建通过 |
| 运行时产物 | Windows 为 `skyuv.exe`，Unix 为 `skyuv` | 安装树和 CPack 内容检查通过 |
| 测试与工作流 | 同步更新 CTest、性能脚本、CI 和 Release workflow | Linux/macOS CI 与本地安装 smoke 通过 |
| 用户文档 | 更新运行时启动命令和交付说明 | 文档示例使用 `skyuv` |

## 不进入本版本

- 性能基线、配置/日志/PID 路径约定和独立 Lua 动态模块 `require` 验证；
- `skyuv_skynet_portable_core` 等内部实现目标的重新命名；
- Actor 调度、网络语义、Lua API 或公共 ABI 变化；
- `v0.2.0` 计划中的运行时与交付收口工作。

## 发布门槛

- Windows、Linux 和 macOS Release workflow 通过；
- `skyuv` 主目标构建成功；
- `install.runtime_smoke` 和 `package.archive_contents` 通过；
- 归档、SHA-256、Changelog、版本文档和 Release 标签使用 `v0.1.1`；
- 版本标签指向完整验收提交，不移动既有版本标签。
