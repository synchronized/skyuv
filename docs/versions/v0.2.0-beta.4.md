## 固定范围

- 处理 cmocka 编码问题，审查既有 MSVC 未初始化、移位、窄化及符号转换诊断。
- 每项给出修复、保留或局部例外结论，记录理由、作用范围和复查条件。

完整采样、诊断处置、缺陷复现和历次验证见
[构建诊断记录](../records/windows-build-diagnostics.md)。2026-10-14 已完成六种 Windows

本次也包含验收中发现的进程指标测试启动同步修复，以及 Windows 构建树的
`project/bin`、`project/cservice`、`project/luaclib` 布局、运行 DLL 检查和真实客户端模块
加载测试。此布局不改变安装包布局，也不代表构建树已包含完整发行运行环境。

## 处置边界

CRT 策略在 Windows Microsoft CRT 工具链下按第三方归属局部设置
`_CRT_SECURE_NO_WARNINGS`；未使用函数例外仅限定 Windows Clang 的 libuv 目标。
已审查的 libuv 日常提示通过 `SKYUV_LIBUV_DIAGNOSTICS=ON` 恢复，具体范围以
[开发指南](../guides/development.md)为准。
不全局关闭警告、不降低等级、不关闭 skyuv 警告即错误，不直接改动第三方工作树。
不机械替换 `_s` 函数或增加未经证明安全的类型转换，不承诺第三方全部零警告。
