# v0.1.0：跨平台运行时与 CMake 消费

## 状态

**已于 2026-09-29 正式发布。** [GitHub Release](https://github.com/synchronized/skyuv/releases/tag/v0.1.0)
承接 `v0.1.0-beta.1` 的跨平台运行时，并纳入 CMake 安装导出和外部 Lua C 模块消费能力。0.x
阶段仍不承诺稳定 ABI。完整验收证据见
[`v0.1.0 发布验收记录`](../records/2026-09-29-v0.1.0-release-acceptance.md)。

## 版本目标

在 Beta 已完成三平台运行时和候选发行包的基础上，补齐 CMake 安装导出、外部 CMake consumer
验证和正式发布记录。

## 固定范围

| 计划 | 本版本收口内容 | 完成条件 |
|---|---|---|
| [007 跨平台交付](../plans/007-cross-platform-delivery.md) | 将候选 Beta 收口为正式 Release | 版本、归档、校验和、三平台交付测试和发布记录一致 |
| [009 CMake 第三方消费与 Lua C 模块接入](../plans/009-cmake-consumer-integration.md) | 提供安装 package、嵌入式消费和外部 Lua C 模块示例 | `find_package`、`add_subdirectory` 和宿主 smoke test 通过 |

## 不进入本版本

- 稳定公共 ABI、第三方 Lua C 模块二进制兼容和 Skynet 内部头文件承诺；
- Windows MSI、macOS PKG/DMG、代码签名、公证、自动更新和 Windows Service；
- 未经数据支持的性能优化或预先承诺的吞吐、延迟比例；
- 新增 Actor 调度模型、网络语义或 libuv 替代 Skynet 调度器的架构改动。

## 已知限制

- 固定 Linux 性能 Runner 和首批回归阈值尚未完成；
- 配置、日志和 PID 路径约定仍沿用现有行为，专项收口移至 `v0.2.0`；
- 独立 Lua 解释器动态模块搜索路径下的真实 `require` 尚未形成自动验收矩阵。

## 发布门槛

- Windows、Linux 和 macOS Release workflow 通过；
- 安装树、CPack 归档和外部 consumer 不包含源码树、构建树或本机路径；
- Changelog、版本文档、发布记录和 GitHub Release 使用同一版本、提交和限制说明；
- 正式标签只能指向完整验收提交，不能移动已公开的 Beta 标签；
- 性能基线、路径约定和独立 Lua `require` 验证作为 `v0.2.0` 的收口任务继续推进。

## 版本身份

正式版本身份由根目录 `CMakeLists.txt` 和 Release workflow 校验：数字版本为 `0.1.0`，
预发布标识为空，标签为 `v0.1.0`。
