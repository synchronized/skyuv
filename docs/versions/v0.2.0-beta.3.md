# v0.2.0-beta.3：libuv 客户端网络

## 状态

范围已确定，尚未实现或发布。当前版本身份仍为 `v0.2.0-beta.1`。
本版本与 `beta.2` 的构建诊断治理分别验收，不扩大后者范围。

## 固定范围

实施 [011：client.socket 的 libuv 改造](../plans/011-client-socket-libuv.md)：

- 保留统一 client.dll/client.so、client.socket 和 client.crypt 的 Lua 接入方式。
- 使用 libuv TCP、专属 I/O 线程和命令队列，提供模块管理的整数连接 ID。
- 保持同步 connect/send、非阻塞 recv、select/poll、shutdown 和安全重复 close。
- 增加可选连接超时、有界接收缓存、完整取消和 Lua 状态销毁流程。
- 保留读半关闭接口及最小平台适配，stdin API 保持现状并完成退出审计。

用户已确认下游不使用原生句柄或 shutdown("r")。精确设计和行为边界以 011 为唯一来源。

## 不进入本版本

共享多实例 I/O 线程、异步 Lua API、收发超时、DNS、IPv6、stdin 整体重写，
以及 Actor 调度改造、任意原生 socket 接管或稳定 ABI 承诺。

## 发布门槛

- 011 验收完成，独立 Lua 与 Skynet 服务两种运行方式均通过。
- 覆盖成功、失败、超时、半关闭、背压、GC、重复关闭、worker 迁移和退出压力测试。
- Windows 本地构建测试、Linux/macOS CI 和三平台发行包验收通过。
- 连接 ID 与原生句柄差异、线程成本和平台边界有说明；变更日志及发布记录一致。

本预览版不替代 v0.2.0 正式版既定的性能、路径和外部 Lua 模块验收门槛。
