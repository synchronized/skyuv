# v0.2.0-beta.1：socket 就绪轮询预览

## 状态

**准备发布为 GitHub Pre-release。** 本版本供跨平台迁移和兼容性验证使用，不建议未经验证直接用于生产环境。skyuv 仍处于 0.x，不承诺稳定 ABI。

## 本次预览范围

- `client.socket.select(read_table, write_table, timeout_seconds)` 等待整数 socket 句柄的读写就绪，并返回就绪句柄表；超时返回 `false`；
- `client.socket.poll` 是 `select` 的别名；
- `skyuv_target_compile_utf8(<target>)` 为明确选择的 MSVC/clang-cl 编译目标启用 `/utf-8`，不改变第三方目标的警告等级。

`client.socket` 仅提供出站 TCP 客户端接口。本预览只增加就绪轮询迁移能力，不提供 lsocket 的监听、accept、UDP、socket 对象方法、DNS 和网卡枚举接口，也不承诺完整 API 或错误语义兼容。
