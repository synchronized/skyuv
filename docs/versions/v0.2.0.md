见[发布页](https://github.com/synchronized/skyuv/releases/tag/v0.2.0)及

## 最终范围

本版本汇总此前 Beta 的 libuv 客户端能力及 Windows 构建修复，并完成以下专项：

| 计划 | 交付结果 |
| --- | --- |
| [006 性能和稳定性](../plans/006-performance-stability.md) | 三平台长时稳定性、固定机自身双窗口基线及跨版本自动复测提示；不自动拒绝合并 |
| [007 跨平台交付](../plans/007-cross-platform-delivery.md) | 三平台正式归档、许可证/版本清单、SHA-256 和公开资产验收 |
| [008 配置、日志与 PID 路径](../plans/008-runtime-paths.md) | 显式新目录入口、旧入口兼容、只读程序树、包外日志、Unix PID 所有权和日志重开 |
| [009 CMake 与 Lua C 模块](../plans/009-cmake-consumer-integration.md) | 源码嵌入、可重定位安装导出及独立 Lua 动态 require 三平台验证 |

三平台完整构建统一生成 `build/<preset>/project/`。具体用户可见变化见
[Changelog](../../CHANGELOG.md#020---2026-10-15)，当前使用与回退方法见
[运行时迁移指南](../guides/runtime-distribution.md#从-beta4-迁移到新目录模式)。

## 兼容边界

- 新目录模式需显式启用 `--runtime-paths`；旧入口保留兼容行为。
- CMake 消费接口仍属实验性，不承诺稳定 ABI 或任意第三方 Lua C 模块二进制兼容。
- 可选独立 Lua 解释器进入构建运行树，不加入 Runtime 发行归档。
- 性能基线只代表已记录的固定 VMware；自动复测提示不等于合并硬门槛或长期统计保证。
- 原版波动定位为可选研究，不依据不稳定比值宣称加速。
- Windows 不支持 Unix daemon 和旧 `int fd` 外部 socket 接管。

其他平台和客户端限制见[运行时指南](../guides/runtime-distribution.md#平台差异与限制)与
[客户端指南](../guides/client-socket.md)。后续版本不在本页追加未实现计划。
