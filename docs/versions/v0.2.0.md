# v0.2.0：运行时与交付收口

## 状态

**准备中。** 本版本承接正式 `v0.1.0`，集中处理 Beta 阶段明确保留的运行时路径、性能证据、
Lua 动态模块验证和后续发布收口。0.x 阶段仍不承诺稳定 ABI。

## 固定范围

| 计划 | 本版本任务 | 验收出口 |
|---|---|---|
| [006 性能和稳定性](../plans/006-performance-stability.md) | 部署 `skyuv-benchmark` 固定 Linux Runner，完成两轮权威采集并形成回归阈值 | 结构化基线记录、环境快照和可重复对比结果 |
| [007 跨平台交付](../plans/007-cross-platform-delivery.md) | 根据性能和路径结果更新正式交付门槛及发布记录 | Release 流程、安装树和迁移说明一致 |
| [008 配置、日志与 PID 路径约定](../plans/008-runtime-paths.md) | 从草案进入实施，明确配置、日志、PID 的目录职责、覆盖方式和迁移行为 | Windows、Linux、macOS 路径验收通过 |
| [009 CMake 第三方消费与 Lua C 模块接入](../plans/009-cmake-consumer-integration.md) | 验证独立 Lua 解释器通过动态模块搜索路径执行真实 `require`，补齐完成记录 | 至少一个平台真实加载通过，其他平台完成构建验证 |

## 不进入本版本

- 稳定公共 ABI 和任意第三方 Lua C 模块二进制兼容；
- 与上述收口任务无关的 Actor 调度、网络语义或平台架构重构；
- 未经基线数据支持的性能优化承诺。

## 发布门槛

- 006、008、009 的验收条件完成，007 同步更新版本与交付记录；
- 性能、路径、动态模块和安装包验证结果均有独立记录；
- 版本文档、Changelog、迁移指南和 Release 说明保持一致；
- 三平台 CI 和相关发布工作流通过。
