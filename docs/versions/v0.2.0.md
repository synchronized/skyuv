# v0.2.0：运行时与交付收口

## 状态

**发布候选，未发布。** 本版本承接正式 `v0.1.1`，集中处理 Beta 阶段明确保留的运行时路径、性能证据、
Lua 动态模块验证和后续发布收口。0.x 阶段仍不承诺稳定 ABI。

CMake 版本身份已准备为 `0.2.0`；本页不是发布后记录，最终候选验证完成后再更新证据。

## 固定范围

| 计划 | 本版本任务 | 验收出口 |
|---|---|---|
| [006 性能和稳定性](../plans/006-performance-stability.md) | 在固定 Runner 完成 skyuv 自身双窗口采集及回归验收；原版配对仅作辅助证据 | 结构化基线记录、环境快照和可重复对比结果 |
| [007 跨平台交付](../plans/007-cross-platform-delivery.md) | 根据性能和路径结果更新正式交付门槛及发布记录 | Release 流程、安装树和迁移说明一致 |

| [009 CMake 第三方消费与 Lua C 模块接入](../plans/009-cmake-consumer-integration.md) | 验证独立 Lua 解释器通过动态模块搜索路径执行真实 `require`，补齐完成记录 | 三平台独立解释器动态加载及消费测试通过 |

## 不进入本版本

- 稳定公共 ABI 和任意第三方 Lua C 模块二进制兼容；
- 与上述收口任务无关的 Actor 调度、网络语义或平台架构重构；
- 未经基线数据支持的性能优化承诺。

## 发布门槛

- 006、008、009 的验收条件完成，007 同步更新版本与交付记录；
- 性能、路径、动态模块和安装包验证结果均有独立记录；
- 版本文档、Changelog、迁移指南和 Release 说明保持一致；
- 三平台 CI 和相关发布工作流通过。

经维护者确认，原版 Skynet 波动根因定位和稳定性能比值不再是发布条件；保留现有对照数据
及限制，不依据不稳定结果宣称加速。skyuv 自身稳定性与回归验收仍须满足计划 006。

当前预览版本为 [`v0.2.0-beta.4`](v0.2.0-beta.4.md)，该预览版不代表以上正式版门槛已满足。

## 发布说明草稿

v0.2.0 汇总此前 Beta 已交付的 libuv 客户端与 Windows 构建修复，并补齐运行路径分离、
三平台统一构建运行树和外部 Lua 动态模块消费验证。当前源码相对 beta.4 的具体变化以
[Changelog 的 0.2.0 候选章节](../../CHANGELOG.md#020---2026-10-15)为准。

新目录模式需显式启用 `--runtime-paths`，旧入口保留兼容行为；部署与回退步骤见
[运行时迁移指南](../guides/runtime-distribution.md#从-beta4-迁移到新目录模式)。运行时归档保持
Runtime 组件边界，独立 Lua 解释器只进入可选构建运行树。CMake 消费接口仍属实验性，
不承诺稳定 ABI、任意第三方 Lua C 模块二进制兼容或固定性能提升比例。

性能数据仅代表已批准的固定 VMware 环境，原版不稳定比值不用于加速宣传；Windows
仍不支持 Unix daemon 和旧 `int fd` 外部 socket 接管。其他已知限制以
[运行时平台限制](../guides/runtime-distribution.md#平台差异与限制)及[客户端指南](../guides/client-socket.md)为准。
本草稿不得在必要验收、版本身份及最终候选验证完成前标为已发布。
