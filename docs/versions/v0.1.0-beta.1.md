# v0.1.0-beta.1：跨平台运行时 Beta

## 状态

**已于 2026-08-19 发布为 GitHub Pre-release。** [GitHub Release](https://github.com/synchronized/skyuv/releases/tag/v0.1.0-beta.1)
包含 Windows、Linux 和 macOS 运行时归档及 SHA-256 校验文件。详细验收证据见
[`delivery-candidate-validation.md`](../records/delivery-candidate-validation.md)。

该版本用于跨平台迁移和兼容性验证，不承诺稳定 ABI，也不建议未经验证直接用于生产环境。

## 版本目标

完成 skyuv 首个可搬运的跨平台运行时闭环，并建立 CMake 构建、安装、打包和持续验证基础。

## 固定范围

| 计划 | 本版本交付 | 公共影响 |
|---|---|---|
| [005 Lua 模块与运行环境](../plans/005-lua-runtime.md) | 三平台 Lua C 模块和 Skynet 运行环境 | 明确模块加载、平台差异和运行时目录边界 |
| [006 性能和稳定性](../plans/006-performance-stability.md) | 跨平台功能、并发和稳定性验证 | 不预先承诺未经测量的性能比例 |
| [007 跨平台交付](../plans/007-cross-platform-delivery.md) | Runtime 安装树、CPack、三平台发行包和发布工作流 | Windows ZIP、Linux/macOS TGZ |

## 不包含

- 稳定的公共 ABI 或任意第三方 Lua C 模块二进制兼容承诺；
- Windows MSI、macOS PKG/DMG、代码签名、公证和自动更新；
- Windows Service 宿主和 Unix 系统服务单元；
- 未经固定 Linux Runner 权威基线支持的性能结论；
- 配置、日志和 PID 路径约定的最终收口，详见 [008 计划](../plans/008-runtime-paths.md)。

## 发布门槛与结果

- Windows、Linux 和 macOS 发行构建、安装验证及归档内容检查通过；
- 最小 Skynet 节点、TCP echo、Lua C 模块和正常退出路径通过安装树验证；
- 三平台 CI、交付测试、归档和 SHA-256 复核通过；
- 固定 Linux 性能 Runner 权威基线和 008 路径约定尚未完成，因此该版本保留 Beta 状态。

## 版本身份

- 数字版本唯一来源：根目录 `CMakeLists.txt` 的 `project(skyuv VERSION ...)`；
- 预发布标识：同文件中的 `SKYUV_VERSION_PRERELEASE`；
- 组合版本：`0.1.0-beta.1`；
- 标签：`v0.1.0-beta.1`。
